Qu'est-ce que c'est ?

What is it?

Un launcher pour rejoindre en un clic notre serveur de jeu de rôle Minecraft Java Edition (Forge 1.20.1) : il installe Java, Forge et les mods du serveur, les met à jour automatiquement, puis lance le jeu et connecte le joueur au serveur.

A launcher to join our Minecraft Java Edition role-playing server (Forge 1.20.1) in one click: it installs Java, Forge and the server's mods, keeps them up to date, then starts the game and connects the player to the server.

Le serveur

The server

Un serveur d'aventure et de jeu de rôle en équipe (jusqu'à une cinquantaine de joueurs) : combat dynamique, magie, exploration de ruines et de donjons, quêtes et histoire originale. Le launcher n'est destiné qu'à ce serveur et à ses joueurs.

A cooperative adventure and role-playing server (up to about fifty players): dynamic combat, magic, exploration of ruins and dungeons, quests and an original story. The launcher is only meant for this server and its players.

Comment ça marche

How it works

  1. Le joueur télécharge et ouvre le launcher.
  2. Il se connecte avec son compte Microsoft, sur la page officielle de Microsoft. Il faut posséder Minecraft Java Edition.
  3. Il clique sur « Jouer » : le launcher télécharge ce qui manque (Java, Forge, mods), vérifie les fichiers, puis lance le jeu.
  4. À chaque mise à jour du serveur, le launcher ne télécharge que les fichiers modifiés.
  1. The player downloads and opens the launcher.
  2. They sign in with their Microsoft account, on Microsoft's official page. Owning Minecraft Java Edition is required.
  3. They click "Play": the launcher downloads what is missing (Java, Forge, mods), checks the files, then starts the game.
  4. When the server is updated, the launcher only downloads the changed files.

Connexion et vie privée, en bref

Sign-in and privacy at a glance

  • Le mot de passe n'est jamais vu ni stocké par le launcher.
  • Les jetons de connexion restent sur l'ordinateur du joueur.
  • Aucune donnée personnelle n'est collectée ni envoyée à nos serveurs.
  • The password is never seen or stored by the launcher.
  • Sign-in tokens stay on the player's computer.
  • No personal data is collected or sent to our servers.
